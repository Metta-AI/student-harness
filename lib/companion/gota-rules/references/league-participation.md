# configured GoTA league participation

This IDE creates one Gods of the Arena BASIC policy for [Gods of the Arena](https://softmax.com/observatory/v2?tab=coworlds&detail=league%3Aleague_3c60897b-25cf-4b37-9d1a-8554c1198f28) (`league_3c60897b-25cf-4b37-9d1a-8554c1198f28`).

1. Edit `hero.bas` and save a revision with its gameplay hypothesis.
2. Upload the policy with `upload_policy`.
3. Request one hosted game with `request_hosted_game`; that tool targets the configured GoTA league.
4. Review the hosted score and replay, then use coaching feedback for the next focused revision.
5. Enter the configured GoTA league with `enter_league` only when the student asks.

The IDE handles the upload and hosted episode. Local game setup is not needed. Read [the policy and host surface](https://softmax.com/gods-of-the-arena/wiki/policy-and-host-surface) for BASIC functions.
