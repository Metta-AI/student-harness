# NeuralHub standings

This IDE targets [NeuralHub at Diablo Valley College](https://softmax.com/gods-of-the-arena/neuralhub) (`league_080e6abb-597b-45e3-ab21-63321905fdd6`).

Use the `league_standing` tool or the league page for live standings and win rate. Other Gods of the Arena leagues have different standings and must not be used to judge a NeuralHub policy. Hosted self-play scores and league win rates are different measurements; compare each with its own sample size.
