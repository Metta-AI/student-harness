# GoTA league standings

This IDE targets [Gods of the Arena](https://softmax.com/observatory/v2?tab=coworlds&detail=league%3Aleague_3c60897b-25cf-4b37-9d1a-8554c1198f28) (`league_3c60897b-25cf-4b37-9d1a-8554c1198f28`).

Use the `league_standing` tool or the league page for live standings and the win/loss/time-limit record. A league win is a destroyed enemy fort; a game that reaches the time limit scores 0 for both sides and is not a win, even though the league page's win column counts those ties. Other Gods of the Arena leagues have different standings and must not be used to judge a policy in this league. Hosted self-play scores and league win rates are different measurements; compare each with its own sample size.
